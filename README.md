**The word: Worcestershire** — nobody on Earth can pronounce it, yet it names a sauce everyone owns. Delete it and the sauce keeps existing, but no one ever has to say "wuss-ter-sheer" wrong in public again.

Entered in [The Word You'd Delete From the Dictionary](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) on make.fun.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (and a byte-identical copy to `entry.txt` in the repo root when writable). Deterministic, no network, no randomness.
